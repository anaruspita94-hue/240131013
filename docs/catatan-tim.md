## Kesepakatan Kerja
1. Branch utama adalah `main`, harus selalu bisa dijalankan.
2. Setiap perubahan dikerjakan di branch terpisah, lalu di-merge ke `main`.
3. Pesan commit harus jelas, contoh: "Tambah README.md".
4. Jangan pernah menyimpan kata sandi, token, atau file `.env` di repositori ini.
5. Sebelum push, selalu cek dengan `git status`.
